# D2 Fetchable Mixin

Intercepts fetch call made on collection.

* Ignore the pending actions fetch done by delayedActions of a collection.
* This mixin is mandatory for all collections which mixes with "nuc/models/mixins/v2.delayed.commandable/v2.delayed.commandable.mixin".
* This mixin need to be added after adding fetchable mixin in collection or after custom fetch override.

## Remarks

In D2SV action are fetched in batches w.r.t. to page size.
"delayedActions" in a collection is responsible to fetching  the promoted actions.
As per fetchable.mixin implementation, when a collections fetch is in-progress, then new fetch will be ignored.
Because of this behavior, when action fetch call is pending in previous page or parent folder, action call will be ignored for next page or navigated child folder.

### How to apply the mixin to a collection

```
var MyCollection = Backbone.Collection.extend({

  constructor: function MyCollection(models, options) {
    Backbone.Collection.prototype.constructor.apply(this, arguments);
    this
      .makeConnectable(options)
      .makeDelayedCommandableV2(options)
      .makeFetchable(options)
      .makeD2Fetchable(options);
  }
  
});

ConnectableMixin.mixin(MyCollection.prototype);
DelayedCommandableV2Mixin.mixin(TaskCollection.prototype);
FetchableMixin.mixin(MyCollection.prototype);
D2FetchableMixin.mixin(MyCollection.prototype);
```
